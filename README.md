# Extrator de Audio YouTube - MP3

Aplicativo desktop para Windows para extracao em lote de audios do YouTube em alta qualidade.

## Como compilar
Execute o arquivo `compilarmp3.bat` para instalar as dependencias, baixar o FFmpeg e gerar o executavel na pasta `dist`.
